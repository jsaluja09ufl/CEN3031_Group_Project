# Flourish
### By **Gator Programmers**

#### Product Description
**Flourish** is a scheduling and productivity platform that combines task management, calendar scheduling, habit tracking, and productivity analytics. Users will be able to create tasks with identifying such as task name, due date, category, priority, and estimated completion time. The application will use this information alongside the user’s availability to organize tasks into appropriate time blocks within their schedule.

#### Vision Statement
Our goal is to create a smart scheduling and productivity platform that helps individuals manage their time, finish activities, and establish good habits.
